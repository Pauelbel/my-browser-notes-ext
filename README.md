# Тихие заметки · 0.3.1

Удаление папки: выберите папку в фильтре слева и нажмите «−» рядом с «＋ Папка». Подтверждение показывает название, число заметок и вложенных папок. Все заметки дерева перемещаются в корзину; при их восстановлении исходные папки создаются заново. Пустые подпапки удаляются. Корневая папка хранилища и служебная корзина недоступны для такого удаления. Другие файлы в папке (например, изображения) не удаляются: непустые каталоги остаются на диске, о чём приложение сообщает.

Корзина открывается отдельным экраном: компактное меню слева, список справа. Флажки выбирают одну или несколько заметок; «Выбрать все» выбирает результаты текущего поиска. При смене поискового запроса выбор сбрасывается. Можно восстановить выбранные записи или удалить навсегда после подтверждения со списком названий. При совпадении имени восстановленная заметка получает новое имя файла. Если папка отключена, операции применяются локально и ожидают синхронизации с диском.

Отдельное расширение Chrome с визуальным редактором и Markdown-файлами. Готовый редактор включён в vendor/; для установки Node.js не нужен.

## Установка и обновление

Откройте chrome://extensions и включите «Режим разработчика». Нажмите «Загрузить распакованное расширение» и выберите notes-next. Если расширение уже установлено, нажмите «Обновить» на его карточке и снова откройте панель. Не удаляйте расширение — удаление стирает его локальные данные.

При первом запуске выберите папку для Markdown-файлов. В дальнейшем открываются заметки и последняя выбранная заметка. Смена папки — отдельно в ⚙ → «Выбрать другую папку».

## Открытие без повторного выбора папки

Локальная копия коллекции хранится в IndexedDB. При закрытии и открытии заметки доступны, даже если Chrome снял разрешение на запись в папку. Изменения сохраняются локально и попадают в устойчивую очередь записи на диск.

Статус различает «Сохранено» (запись в файлы завершена) и «В браузере · ожидает записи в папку». При отключённой папке нажмите «Подключить папку» для синхронизации, выбирать её заново не нужно. Если Chrome предложит «Разрешать при каждом посещении», этот вариант избавляет от повторных разрешений. Приложение само не может выдавать себе разрешение Chrome.

При первом обновлении с версии 0.1 может понадобиться однократно подключить прежнюю папку, чтобы создать локальную копию существующих заметок. После этого для просмотра и редактирования повторное разрешение не требуется. Пока папка отключена, внешние изменения файлов не видны. Очистка данных или удаление расширения удаляет локальную копию и ещё не записанные на диск изменения; синхронизированные .md-файлы остаются в выбранной папке.

## Редактор и теги

- Визуальный редактор: жирный, курсив, заголовки, списки, задачи, цитаты, отмена и повтор. Кнопка T× снимает форматирование. Синтаксис Markdown не показывается, файлы остаются Markdown.
- Теги добавляются через пробел, Enter или запятую. Можно вставить сразу «работа идеи личное». Повторы убираются; начальный # необязателен. Нажатие × удаляет тег. Ранее сохранённые теги с пробелами остаются целыми метками.
- Папки, поиск по названию/тексту/тегам/пути, корзина .trash, восстановление в исходную папку.
- Ctrl+S — сохранить; Ctrl+K — поиск; Ctrl+B / Ctrl+I — форматирование.
- Последняя открытая заметка восстанавливается при следующем запуске.

## Файлы и конфликты

В начале .md-файла находится служебный HTML-комментарий с названием и тегами, далее — Markdown. Редактирование названия или тегов не пересериализует тело заметки. Изменение текста приводит Markdown к формату визуального редактора. Нестандартные Markdown-расширения могут отображаться иначе; базовые заголовки, выделения, списки, задачи, таблицы, ссылки и код поддерживаются.

«Обновить» перечитывает диск. Приложение проверяет исходное содержимое перед записью; при конфликте внешняя версия не перезаписывается, локальная версия и очередь остаются в браузере, а синхронизация останавливается с указанием файла. Перенос в корзину работает без доступа к диску и выполняется при подключении. Смена папки открывает другую коллекцию, не перемещая предыдущие файлы.

## Панель слева

⚙ → «Открыть настройки Chrome» → «Внешний вид» → сторона боковой панели. Положение задаётся самим Chrome для всех боковых панелей.

## Разработка и проверка

pnpm install --frozen-lockfile, затем node build.mjs — пересобрать локальный редактор Tiptap. node --test tests/storage.test.js — тесты файлового слоя, очереди и тегов. node serve.mjs — проверка на localhost:4173. Страница tests/browser.html создаёт изолированную тестовую коллекцию OPFS, не пользовательские файлы.
