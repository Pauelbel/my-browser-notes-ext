Место для ваших мыслей

Выберите папку на компьютере.
Каждая заметка — обычный Markdown-файл, который остаётся у вас.

Без аккаунта. Без облака. Без аналитики.

Корзина

Удалить заметки навсегда?

    Восстановить их из корзины будет невозможно.

    Удалить папку?

    Заметки попадут в корзину вместе с содержимым вложенных папок. При восстановлении заметок их папки будут созданы заново.

    Настройки

    Папка с заметками

    Папка ещё не выбрана.

    Панель слева или справа

    В Chrome откройте «Внешний вид» → «Боковая панель» и выберите левую или правую сторону. Настройка действует на все боковые панели браузера.

    Больше места

    Заметки хранятся в .md-файлах. Удалённые — в подпапке .trash. Переключение папки не переносит старые заметки.
