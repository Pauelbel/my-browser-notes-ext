В архиве найдены заметки

При объединении заметки из выбранной папки появятся в расширении. Заметки, которые уже есть в расширении, тоже будут сохранены в эту папку.

Если у заметки есть отличающаяся копия в той же папке, сохранятся обе версии. Версия из расширения получит пометку «браузерная копия», а версия из архива останется с исходным названием. Одинаковые версии одного файла не дублируются.

Существующие файлы архива не перезаписываются. Подпапки сохраняются, посторонние файлы остаются на месте.

«Заменить заметками из папки»: в браузере останутся только заметки и корзина из выбранной папки. Текущие браузерные заметки и корзина будут удалены, а очередь их записи в архив — очищена. Файлы в выбранной папке не изменятся. Если прочитать папку не удастся, ваши заметки сохранятся.

Удалить заметки навсегда?

    Восстановить их из корзины будет невозможно.

    Удалить папку?

    Заметки попадут в корзину вместе с содержимым вложенных папок. При восстановлении заметок их папки будут созданы заново.

    Выберите папку архива

    Заметки уже сохранены в Chrome. Выберите папку для резервных Markdown-копий.

    Настройки

    Резервная папка

    Резервная папка не выбрана.

    Заметки хранятся внутри Chrome. Резервные .md-копии отправляются после сохранения. Пока приложение открыто и видно, архив проверяется каждые 30 секунд: новые Markdown-файлы и папки появляются в списке автоматически. Для этого нужен доступ к папке архива.

    Меню заметок

    Меняет расположение списка заметок относительно редактора.

    Положение панели Chrome

    На странице настроек Chrome найдите «Расположение боковой панели». В списке «Панели Chrome» выберите «Слева» или «Справа».
